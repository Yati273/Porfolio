Hardware & software

Arduino Uno, potentiometer, water sensor, eight LEDs, resistors, relay and breadboard.

Select a photograph to enlarge it.

02 / IMPLEMENTATION

How the system works

  1. Read inputs

    Read analog signals from the potentiometer and water sensor.

  2. Process readings

    Use Arduino programming to determine which input controls the LED sequence.

  3. Control outputs

    Update the LEDs and relay according to the selected input and programmed conditions.
