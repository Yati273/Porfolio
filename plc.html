Automated Food Preparation System

A PLC-controlled food preparation concept that uses four pneumatic stations to simulate a complete serving cycle.

01 / OVERVIEW

Project objective

A PLC-controlled food preparation concept that uses four pneumatic stations to simulate a complete serving cycle.

Hardware & software

PLC ladder logic, pneumatic cylinders, solenoid valves, proximity sensors, timers, counters and HMI.

Select a photograph to enlarge it.

02 / IMPLEMENTATION

How the system works

  1. Bowl transfer

    Cylinder A moves the bowl into the process.

  2. Dispensing

    The dispensing station uses timed control to deliver sauce.

  3. Lid placement

    Cylinder C secures the lid before the next stage.

  4. Cutlery dispensing

    Cylinder D dispenses cutlery; a counter tracks completed bowls.

03 / LEARNING

Skills developed

Sequence control, I/O mapping, electro-pneumatic connections and understanding automated production processes.
